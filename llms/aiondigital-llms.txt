## What an agent can and cannot do here

Aion Digital has **no public API**. It markets an API platform — the Aion Rubix page lists an API
gateway, "API management with API analytics", microservices/containers and modular middleware with
pre-integrations — and a 2019 Open Bank Project partnership gave its bank customers an API catalogue
of 200+ APIs plus a sandbox. None of that is reachable by a third party. There is no developer
portal, no API reference, no OpenAPI/AsyncAPI/GraphQL/SOAP contract, no sandbox signup, no API key
issuance and no published pricing. Every developer-facing call to action is "Request a demo",
routing to https://aiondigital.com/contact/.

The API surfaces Aion Digital builds are deployed inside its customers' banks. An agent evaluating
this company should treat it as a vendor to integrate with under contract, not as an API to call.
